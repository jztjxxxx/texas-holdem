# 德州扑克

**▶ Play it now in your browser / 点开就能玩：https://jztjxxxx.github.io/texas-holdem/**

单挑机器人德州扑克，为 2026-11-21 Monad Blitz @广州 准备的备用项目。
对局在前端跟机器人打，完整可玩；配套一个极简 Solidity 合约，把战绩存到 Monad 测试网上。

## 怎么玩

直接打开 `frontend/play.html`（单文件版，什么都不用配），点“开始第一手”。
发牌是荷官式逐张发的：先机器人一张、你一张、再各一张，你的牌落桌时翻开；翻牌/转牌/河牌都是翻转着亮出来的，摊牌时机器人的底牌也会翻开。动画期间按钮会锁定，牌发完自动解锁。
（`frontend/index.html` + `poker-engine.js` 是拆分版，内容相同，两个文件要放在一起才能打开。）

- 每人 1000 筹码（游戏币，不是真钱、也不是真代币）
- 你是小盲 10，机器人大盲 20，翻前跟注 10 开始
- 操作只有三个：弃牌、让牌/跟注、加注
- 加注金额自由选：牌桌上有一排赌场式圆形筹码（10 / 25 / 50 / 100 / 250），点筹码往上攒金额，还有“全下”和“重置”筹码；攒好后按加注按钮打出去（最小加注 10，机器人那边的加注仍是固定 40）
- 一路打到河牌自动摊牌比大小，平局分池

## 加了哪些有趣的玩法

1. **道具卡（每手随机一张，每手限用一次）**
   - 👀 透视眼：偷看机器人一张底牌
   - 🔄 乾坤大挪移：把你的第二张底牌换成牌堆下一张
   - ✖️2 双倍奖池：本手赢家额外从庄家奖池拿到等同奖池的奖励
   - 🛡️ 护盾：本手输了，返还你投入的一半
2. **会说话的机器人**：机器人阿莫会根据局势放狠话、让牌、弃牌，还会偶尔诈唬；它诈唬赢了会自己得意地承认，摊牌时就知道它刚才在虚张声势
3. **连胜火焰**：连胜会攒火，每满 3 连胜额外奖励 30 筹码
4. **成就墙（7 个）**：第一胜、三连胜、全下获胜、同花以上、葫芦以上、诈唬成功、打满 10 手，解锁了会弹庆祝横幅，进度存在浏览器里
5. **大牌庆祝**：你打出同花以上的牌型会弹横幅，机器人会当场服气
6. **战绩上链**：打完的手数、胜场、最大牌型可以一键汇总存到 Monad 测试网（见下），Demo 时可以讲“连打牌战绩都上链存证”

## 简化规则（和正式德州的区别，先说清）

这是为了一天黑客松和练手做的简化版，不是完整德州规则：

- 只有单挑（你 vs 机器人），没有多人桌
- 每条街机器人最多加注一次，玩家对机器人的加注只回应一次（跟/弃），机器人对玩家的加注不反加
- 没有边池；全下后直接发完公共牌摊牌
- 盲注固定，不轮换庄家
- 道具、双倍、护盾返还、连胜奖励都是趣味层，奖励由“庄家奖池”出，不从对方筹码里扣，所以整场总筹码不守恒，这是故意的游戏化设计（引擎内部的正常对局结算是守恒的，已测试）

## 文件说明

| 文件 | 是什么 |
|---|---|
| `frontend/poker-engine.js` | 纯逻辑引擎：洗牌、7 选 5 牌型评估、机器人 AI、一手牌状态机。不依赖页面，Node 里也能跑 |
| `frontend/index.html` | 游戏页面：牌桌、道具、成就、机器人对话、战绩上链入口 |
| `contracts/MonadPokerScore.sol` | 战绩合约：`recordMatch(手数, 胜场, 最大牌型)` 累加存上链，约 40 行 |
| `frontend/abi.json` | 战绩合约的编译产物，留档用 |

## 战绩上链（可选，步骤和留言墙一样）

1. 钱包添加 Monad Testnet（Chain ID 10143，RPC https://testnet-rpc.monad.xyz），去 https://faucet.monad.xyz 领测试币
2. 打开 https://remix.ethereum.org ，把 `MonadPokerScore.sol` 粘进去编译，用 Injected Provider（MetaMask，连测试网）部署，复制合约地址
3. 回到游戏页，展开底部“战绩上链”，粘地址保存；打几手后点“提交待上链战绩”，钱包确认即可

不部署也能完整玩，上链只是把战绩存证，待上链手数会攒着不丢。
